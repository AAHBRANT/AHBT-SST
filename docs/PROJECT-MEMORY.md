# Project Memory

## Nome do aplicativo

- O nome correto do app é **G-SST**.
- Não usar "HUB GENESIS SST" como nome do aplicativo.
- Quando precisar exibir a obra/app em comprovantes, canhotos, títulos, handoffs ou mensagens para o usuário, usar **G-SST**.

## Fotos e geolocalização — diretrizes aprovadas em 28/09/2026

- Todas as fotos devem ter data, hora e local da captura, com geolocalização.
- Acidentes devem manter a descrição do local e exigir três fotos do local, cada uma com seus próprios dados de captura.
- Se a localização falhar, preservar o preenchimento como rascunho e manter a pendência até regularizar; não atribuir uma localização posterior como se fosse a original.
- Planejamento e primeira implementação registrados em [Fotos com data, hora e geolocalização](superpowers/specs/2026-09-28-fotos-geolocalizadas-design.md). A validação de novas fotos já está ativa em DDS, treinamentos, inspeções e acidentes; fotos legadas sem metadados são preservadas.
